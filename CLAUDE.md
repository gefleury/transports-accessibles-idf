## Running tests

```bash
python -m pytest tests/
# or
python -m unittest discover tests/
```

Tests live in `tests/test_prepare_data.py` and are skipped automatically when the relevant files are absent. Three test classes:
- `TestInputFileStructure` — verifies raw source files have the expected columns and valid values; catches API format changes.
- `TestMetroAccessibility` — tests `prepare_accessibility_metro` against the raw stops file (Châtelet line 11 → `false`, line 14 → `true`, Porte des Lilas line 11 → `true`, etc.).
- `TestProcessedOutput` — end-to-end tests on `data/processed/` (run `python src/prepare_data.py` first); catches bugs in `join_accessibility`, `join_stops_to_lines`, and `join_line_accessibility`.

## Architecture

### Data

`data/` is gitignored. Raw source files:
- `traces-des-lignes-de-transport-en-commun-idfm.geojson` — line traces (geometry + metadata)
- `traces-des-lignes-de-transport-en-commun-idfm.csv` — tabular version
- `arrets-lignes.geojson` — stops per line (~73k rows, join key: `id` → lines `route_id`); key columns: `stop_id`, `stop_name`, `route_long_name` (line identifier, e.g. `"11"` for metro line 11), `shortname` (same value), `mode` (raw values: `Bus / Metro / Tramway / LocalTrain / RapidTransit / regionalRail / …`)
- `sdap-arrets-associes.csv` — wheelchair accessibility for bus stops; one row per (stop, line); key columns: `stop_id`, `route_long_name`, `ArRAccessibility` (`true / partial / false`); accessibility is consistent across lines for a given stop
- `accessibilite-en-gare.csv` — wheelchair accessibility for train/RER stations (SNCF); join key: strip `stop_point:` prefix from `stop_point_id` → `stop_id`; `accessibility_level_id` values 1/3/4/6 mapped to `false / partial / partial / true`

Processed files (generated by `src/prepare_data.py`, also gitignored) live in `data/processed/`:
- `lines.geojson` — cleaned lines with normalised `route_color` (prefixed with `#`), mapped `mode` (French labels), and per-line accessibility summary flags (`has_accessible / has_partial / has_inaccessible / has_unknown`)
- `stops.geojson` — cleaned stops enriched with `route_short_name`, `route_long_name`, `route_color`, `mode` from lines; orphan stops (no matching route_id) are dropped; `ArRAccessibility` column (`true / partial / false / unknown`) added from all accessibility sources

Key columns in processed files: `mode` (Bus / Métro / RER / Tramway / Transilien / TER / Navette aéroport / Autre), `route_color`, `route_short_name`, `route_long_name`, `operatorname`. Bus dominates with ~1950 line traces and tens of thousands of stops. SNCF-operated bus lines are dropped from lines (suspected data errors).

### `src/prepare_data.py`

One-shot script to build `data/processed/`. Re-run from the repo root whenever raw source files change:

```bash
python src/prepare_data.py
```

**Key design**: all `prepare_accessibility_*` functions return a DataFrame with three columns — `stop_id`, `route_long_name`, `ArRAccessibility` — so `join_accessibility` can join on `(stop_id, route_long_name)`. This allows the same physical stop to carry different accessibility statuses on different lines (e.g. Châtelet is `false` on line 11 but `true` on line 14).

Key functions:
- `map_mode(series)` — maps raw mode strings to French labels
- `prepare_lines(gdf_lines, gdf_stops)` — column selection, drops SNCF bus lines, normalises `route_color`, merges `mode` from stops
- `prepare_stops(gdf)` — column selection only
- `join_stops_to_lines(lines, stops)` — lines LEFT JOIN stops; orphan stops fall off naturally; adds `route_short_name`, `route_long_name`, `route_color`, `mode` to stops; drops the rare stops with no mode (lines present in the lines file but absent from `arrets-lignes.geojson`)
- `prepare_accessibility_bus(df)` — returns `(stop_id, route_long_name, ArRAccessibility)` directly from the CSV (which already has `route_long_name`)
- `prepare_accessibility_tramway(gdf_stops)` — all Tramway stops → `"true"`; returns `(stop_id, route_long_name, ArRAccessibility)`
- `prepare_accessibility_metro(gdf_stops)` — line ≥ 14 → `"true"`; line 11 named stations → `"true"`; all others → `"false"`; returns one row per `(stop_id, route_long_name)` pair
- `prepare_accessibility_train(df, gdf_stops)` — maps `accessibility_level_id` to vocabulary, merges with `gdf_stops` to get `route_long_name`; returns `(stop_id, route_long_name, ArRAccessibility)`
- `join_accessibility(stops, *accessibility_dfs)` — concatenates sources in order (bus < tramway < metro < train, last wins), deduplicates on `(stop_id, route_long_name)`, left-joins onto stops; unmatched stops get `"unknown"`
- `join_line_accessibility(lines, stops)` — aggregates per-route accessibility into four boolean flags on lines

Metro accessibility rules (line 11 accessible stations): Porte des Lilas, Mairie des Lilas, Serge Gainsbourg, Romainville - Carnot, Montreuil - Hôpital, La Dhuys, Coteaux Beauclair, Rosny-Bois-Perrier.

### `src/geoplotter.py`

`GeoPlotter` wraps a GeoPandas GeoDataFrame and a Folium map:

- `__init__(gdf, geom_col, tiles, zoom_start)`: validates/converts CRS to EPSG:4326, computes map centre via Lambert-93 (EPSG:2154) centroids, creates `folium.Map`. Default `zoom_start=10` (Paris region).
- `add_geodata_to_map`: iterates rows, resolves colour (flat default or via `color_col` + `colormap` dict/callable), builds tooltips, dispatches to the appropriate `add_*` method. Skips rows where the geometry column is not a valid geometry object.
- `add_geodata_from_gdf_to_map`: overlays a second GeoDataFrame by temporarily swapping `self.gdf` and `self.geom_col`, delegating to `add_geodata_to_map`, then restoring them — avoids redundant map/centroid computation.
- Points are rendered as `folium.CircleMarker` (pixel radius, constant across zoom levels).
- Geometry dispatch: `add_geometry_element` routes to `add_linestring / add_multilinestring / add_point / add_multipoint / add_polygon / add_multipolygon / add_geometrycollection`. 3D geometries are flattened to 2D before rendering.

Notebooks import via `sys.path.insert(0, "../src")` then `from geoplotter import GeoPlotter`.

### `app.py`

Streamlit app at the repo root. Loads from `data/processed/` only.

- `load_data()`: cached with `@st.cache_data`, reads both processed GeoJSONs once.
- `apply_filters(gdf, mode_filters)`: filters by mode and optionally by specific lines; `mode_filters` maps mode → `(enabled, selected_lines)`.
- Sidebar layout: accessibility checkboxes at top (always applied to both lines and stops) → per-mode expanders with line multiselects. Bus is special-cased: no "show all" checkbox, enabled only when an operator or specific lines are selected.
- Lines are always filtered to those having at least one stop matching the selected accessibility statuses (using `has_accessible / has_partial / has_inaccessible / has_unknown` boolean flags on lines).
- `stops_filtered` is derived from `lines_filtered["route_id"]`, so all line filters (mode, operator, accessibility) propagate to stops automatically.
- Line names are sorted with natural sort (`_line_sort_key`) so embedded numbers compare numerically: `T3a < T3b < T4 < T10`.
- Stops are coloured by `ArRAccessibility` (green / orange / red / gray) via `ACCESSIBILITY_COLORS`.
- A warning is shown when the selected stop count exceeds 2000.
- Map rendered via `st_folium` with `returned_objects=[]` (avoids unnecessary round-trips to Python).

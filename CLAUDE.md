## Architecture

### Data

`data/` is gitignored. Raw source files:
- `traces-des-lignes-de-transport-en-commun-idfm.geojson` — line traces (geometry + metadata)
- `traces-des-lignes-de-transport-en-commun-idfm.csv` — tabular version
- `arrets-lignes.geojson` — stops per line (~73k rows, join key: `id` → lines `route_id`)
- `sdap-arrets-associes.csv` — wheelchair accessibility status for bus stops; join key: `stop_id`; values: `true / partial / false / unknown`
- `accessibilite-en-gare.csv` — wheelchair accessibility for train/RER stations (SNCF); join key: strip `stop_point:` prefix from `stop_point_id` → `stop_id`; levels 1/3/4/6 mapped to `false / partial / partial / true`. Note: `operatorname == 'SNCF'` in `arrets-lignes.geojson` also includes SNCF-operated bus stops which are not in this file — join on `mode` in `{LocalTrain, RapidTransit, regionalRail}` to avoid spurious nulls.

Processed files (generated by `src/prepare_data.py`, also gitignored) live in `data/processed/`:
- `lines.geojson` — cleaned lines with normalised `route_color` (prefixed with `#`)
- `stops.geojson` — cleaned stops enriched with `route_type`, `route_short_name`, `route_color` from lines; orphan stops (no matching route_id) are dropped; `ArRAccessibility` column added from both accessibility files (train takes precedence where both cover the same stop)

Key columns: `route_type` (Bus / Subway / Tram / Rail / Funicular / CableWay), `route_color`, `route_short_name`, `route_long_name`, `operatorname`. Bus dominates with ~1950 line traces and tens of thousands of stops.

### `src/prepare_data.py`

One-shot script to build `data/processed/`. Re-run from the repo root whenever raw source files change:

```bash
python src/prepare_data.py
```

Key functions: `prepare_lines`, `prepare_stops` (column selection), `join_stops_to_lines` (lines LEFT JOIN stops — orphan stops fall off naturally), `prepare_accessibility_bus`, `prepare_accessibility_train` (clean and normalise each accessibility file to `stop_id` + `ArRAccessibility`), `join_accessibility` (combines both tables, train takes precedence, left-joins onto stops).

### `src/geoplotter.py`

`GeoPlotter` wraps a GeoPandas GeoDataFrame and a Folium map:

- `__init__(gdf, geom_col, tiles, zoom_start)`: validates/converts CRS to EPSG:4326, computes map centre via Lambert-93 (EPSG:2154) centroids, creates `folium.Map`. Default `zoom_start=10` (Paris region).
- `add_geodata_to_map`: iterates rows, resolves colour (flat default or via `color_col` + `colormap` dict/callable), builds tooltips, dispatches to the appropriate `add_*` method. Skips rows where the geometry column is not a valid geometry object.
- `add_geodata_from_gdf_to_map`: overlays a second GeoDataFrame by temporarily swapping `self.gdf` and `self.geom_col`, delegating to `add_geodata_to_map`, then restoring them — avoids redundant map/centroid computation.
- Points are rendered as `folium.CircleMarker` (pixel radius, constant across zoom levels).
- Geometry dispatch: `add_geometry_element` routes to `add_linestring / add_multilinestring / add_point / add_multipoint / add_polygon / add_multipolygon / add_geometrycollection`. 3D geometries are flattened to 2D before rendering.

Notebooks import via `sys.path.insert(0, "../src")` then `from geoplotter import GeoPlotter`.

### `app.py`

Streamlit app at the repo root. Loads from `data/processed/` only.

- `load_data()`: cached with `@st.cache_data`, reads both processed GeoJSONs once.
- `apply_filters(gdf, selected_types, selected_lines)`: shared filter logic applied identically to lines and stops so they always stay in sync.
- Sidebar: route type checkboxes (Bus unchecked by default) → line multiselect (options update based on selected types) → "Afficher les arrêts" checkbox → accessibility filter checkboxes (`true / partial / false / unknown`).
- Stops checkbox defaults to off when filtered stop count exceeds `MAX_STOPS_DEFAULT_ON` (2000) to avoid browser crashes. A warning is shown if the user overrides this.
- Stops are coloured by `ArRAccessibility` (green / orange / red / gray) via `ACCESSIBILITY_COLORS`, independently of the line colour.
- Map rendered via `st_folium` with `returned_objects=[]` (avoids unnecessary round-trips to Python).

Contact

Un avis, une remarque ? Contactez-moi!

Ce site est un projet personnel, développé sur mon temps libre, pour aider à mieux anticiper l'accessibilité des trajets en fauteuil roulant en Ile-de-France. Il est forcément perfectible : un bug sur la carte, une suggestion d'amélioration, une remarque ou même une critique ... tout est bienvenu! Cela m'aide à le rendre plus utile. N'hésitez pas à m'écrire !

Vous pouvez me contacter directement à contact@transports-accessibles-idf.fr.

Soutenir le projet

Pour optimiser l'expérience utilisateur, j'ai fait le choix de ne pas inclure de publicité sur ce site. S'il vous est utile et que vous avez envie de m'encourager à le maintenir, vous pouvez m'offrir un pourboire sur Buy Me a Coffee.

Contribuer au projet

Envie de mettre la main dans le code ? Ce site est open source : le code est disponible sur GitHub. N'hésitez pas à consulter les issues, proposer une correction ou une amélioration.

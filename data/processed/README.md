# Données traitées

Les fichiers de ce répertoire (`lines.geojson`, `stops.geojson`) sont dérivées des données sources d'[Île-de-France Mobilités](https://data.iledefrance-mobilites.fr):
- [Tracés des lignes](https://data.iledefrance-mobilites.fr/explore/dataset/traces-des-lignes-de-transport-en-commun-idfm/information/) — ODbL
- [Arrêts des lignes](https://data.iledefrance-mobilites.fr/explore/dataset/arrets-lignes/information) — ODbL
- [Accessibilité des arrêts bus](https://data.iledefrance-mobilites.fr/explore/dataset/sdap-arrets-associes/information/) — ODbL
- [Accessibilité en gare](https://data.iledefrance-mobilites.fr/explore/dataset/accessibilite-en-gare/information/) — Licence Ouverte Etalab

Conformément aux conditions de la licence [ODbL](https://opendatacommons.org/licenses/odbl/), ces fichiers dérivés sont distribués sous la même licence **ODbL**.
